🤖 Telegram বট সংযোগ

এই HTML ফাইলটি একটি ফ্রন্টএন্ড ডেমো। এটিকে Telegram বটের সঙ্গে যুক্ত করতে:

  1. Telegram-এ @BotFather ব্যবহার করে বট তৈরি করুন।
  2. টোকেনটি সার্ভারের environment variable-এ রাখুন—HTML/JavaScript-এ নয়।
  3. Node.js বা Python ব্যাকএন্ড তৈরি করে Telegram Bot API-এর সঙ্গে যোগাযোগ করান।
  4. চার্ট AI, পেমেন্ট যাচাই, রেফারেল গণনা ও অ্যাডমিন অনুমোদন সার্ভারে বাস্তবায়ন করুন।
সতর্কতা: বট টোকেন, পেমেন্ট API secret, OTP বা গোপন তথ্য এই পেজে লিখবেন না।
ডেমো HTML · কোনো বাস্তব পেমেন্ট, ট্রেড বা বট API কল করা হয় না। বাস্তব ব্যবহারের আগে নিরাপদ ব্যাকএন্ড প্রয়োজন।
